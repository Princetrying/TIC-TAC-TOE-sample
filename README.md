# Tic Tac Toe Game

## Description
A simple Tic Tac Toe game made using HTML, CSS, and Vanilla JavaScript. This project was mostly vibe-coded — I only manually adjusted some colors, spacing, and alignment while experimenting with the overall design and gameplay.

The goal of this project was mainly to explore how JavaScript handles game logic, button interactions, and DOM manipulation while also practicing responsive web design. It features a clean glass-morphic style, hover effects, win detection, and a layout that works on both desktop and mobile devices.

Everything was built using pure front-end technologies without external libraries or frameworks.

## Features
- Two-player local gameplay
- Turn indicator
- Automatic win and draw detection
- Highlighted winning combination
- Restart button
- Responsive design for desktop and mobile
- Simple glass-morphic UI design

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
